Engineering Rigor

Technical Constraints & Architecture

Designed according to strict academic and production criteria.

1. Pure Vanilla Web Stack

Constructed with 100% native HTML5, CSS3, and ES6+ JavaScript. Completely free of frontend frameworks (no React, Vue, Angular), zero bundlers (no Webpack, Vite), and zero NPM runtime dependencies.

2. Double-Click & Subpath Ready

Can be opened simply by double-clicking index.html from local storage (working seamlessly over the file:// protocol) or hosted on GitHub Pages or Netlify subpaths.

3. Strict Sandboxed Isolation

Each assessment runs inside an isolated <iframe> container with proper sandboxing. Code, styles, and scripts from one exercise can never collide with or pollute another exercise.

4. Hand-Written Syntax Highlighter

The Code viewer utilizes a bespoke, zero-dependency token highlighter parsing HTML, CSS, and JavaScript with line numbers, code copying, and one-click file downloading.

5. Extensible Data-Driven Manifest

Adding a 43rd assessment requires only creating a new folder and adding one JSON-like entry to data/assessments.js. The listing, search, filters, and pager adapt automatically.

6. Accessibility & Responsiveness

Complies with WCAG AA contrast standards, keyboard navigability, semantic tags, and responsive design scales fluidly from 360px mobile displays up to 1920px widescreen monitors.
